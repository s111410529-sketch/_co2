# ALU 證明：在特定控制位元下的輸出（第二章：布林算術）

本課程採用 Nand2Tetris 的 16 位元 Hack ALU，其輸入為 x[16]、y[16]，控制位元為
zx、nx、zy、ny、f、no，運算依下列順序進行：

```
if (zx == 1) x := 0        // 把 x 歸零
if (nx == 1) x := !x       // 對 x 逐位元取反
if (zy == 1) y := 0        // 把 y 歸零
if (ny == 1) y := !y       // 對 y 逐位元取反
if (f  == 1) out := x + y  // 二補數加法
else         out := x & y  // 逐位元 AND
if (no == 1) out := !out   // 對輸出逐位元取反
```

## 題目給定：nx=0, zx=1, ny=0, zy=0, f=1, no=1

照上述定義逐步推導：

| 步驟 | 條件 | 動作 | 結果 |
|------|------|------|------|
| 1 | zx=1 | x := 0 | x = 0 |
| 2 | nx=0 | 不做 !x | x = 0 |
| 3 | zy=0 | 不歸零 | y = y |
| 4 | ny=0 | 不取反 | y = y |
| 5 | f=1 | out := x + y | out = 0 + y = y |
| 6 | no=1 | out := !out | **out = !y** |

因此，緒照題目這組位元，ALU 實際算出的結果是 **out = !y（NOT y）**，並**不是 x-y**。
關鍵原因：`zx=1` 已經先將 x 歸零（x=0），後續再也拿不回原來的 x。

> 題目似乎把 `zx` 與 `nx` 的控制值打反了。Nand2Tetris 標準 ALU 中
> 「out = x-y」對應的組合是 **zx=0, nx=1**（其餘 zy=0, ny=0, f=1, no=1 相同），
> 以下為其完整證明。

## 正確組合 zx=0, nx=1, zy=0, ny=0, f=1, no=1 ⟹ out = x-y

| 步驟 | 條件 | 動作 | 結果 |
|------|------|------|------|
| 1 | zx=0 | 不歸零 | x = x |
| 2 | nx=1 | x := !x | x = !x |
| 3 | zy=0 | 不歸零 | y = y |
| 4 | ny=0 | 不取反 | y = y |
| 5 | f=1 | out := x + y | out = !x + y |
| 6 | no=1 | out := !out | out = !(!x + y) |

### 代數證明（二補數）

在 n 位元二補數中，逐位元取反恰等於 `!a = 2ⁿ − 1 − a`，因此：

```
out = !(!x + y)
    = 2ⁿ − 1 − ( (2ⁿ − 1 − x) + y )
    = 2ⁿ − 1 − (2ⁿ − 1) + x − y
    = x − y
```

得證 **out = x - y**。✓

### 數值驗證（n=16，x=5，y=3）

| 量 | 二進位 | 十進位（二補數） |
|------|------------------|------------------|
| x | 0000 0000 0000 0101 | 5 |
| !x | 1111 1111 1111 1010 | −6 |
| !x + y | 1111 1111 1111 1101 | −3 |
| out = !(!x + y) | 0000 0000 0000 0010 | **2 = 5 − 3 ✓** |

## 對照：標準 ALU 運算表（節錄）

| zx | nx | zy | ny | f | no | out |
|----|----|----|----|----|----|-----|
| 0 | 1 | 0 | 0 | 1 | 1 | x − y |
| 0 | 0 | 0 | 1 | 1 | 1 | y − x |
| 1 | 1 | 0 | 0 | 0 | 0 | y |
| 0 | 0 | 1 | 1 | 1 | 1 | −x |
| 1 | 1 | 0 | 0 | 1 | 1 | −y |
| 0 | 0 | 1 | 1 | 1 | 0 | x − 1 |
| 1 | 1 | 0 | 0 | 1 | 0 | y − 1 |
| 0 | 0 | 0 | 0 | 1 | 0 | x + y |

由上表可見「x − y」的標準組合確實是 zx=0, nx=1，與本證明一致。
